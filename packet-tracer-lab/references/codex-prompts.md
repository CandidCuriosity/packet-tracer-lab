# Agent任务示例

替换尖括号中的文档、输出目录和验收要求；先定位实际Skill安装目录及当前工具schema。

## 实验执行

```text
使用$packet-tracer-lab，根据<实验文档绝对路径>完成<实验名称>。
先读取当前拓扑与文件状态，已有内容先原生另存副本。
列设备/地址/端口/线缆表，原文冲突沿用当前已确认方案，未确认处先核对。
配置后独立读回，按<验收要求>检查通信和模拟过程。
原始返回、截图、报告和新工程写入<结果目录>，仅填写真实通过及未完成项。
```

## 实验2首次学习

```text
使用$packet-tracer-lab完成交换机学习实验，先读lab-runbook和lab2-simulation。
首次ping前保存初始MAC/ARP，之后观察源MAC学习、ARP泛洪与回复、已知单播和清表。
切过滤器后重记历史基线，只以新事件证明广播进展；待处理终端不要随意关闭。
观察后再做最终ping，原生保存与重开分别验收。地址按当前已确认方案配置。
```

## 只读排障

```text
使用$packet-tracer-lab排查<实际现象>，先读troubleshooting。
先取窗口/进程、bridge、拓扑、接口和主机配置，再给证据及下一步。
暂不重启PT、删除设备或重建拓扑。
```

## 会话加载确认

报告实际所读SKILL.md路径和版本，确认当前工具发现结果、bridge与真正PT读回。
缺前置时记录实际阻塞，不用猜测的工具或旧会话结果替代。
报告格式遵守用户选择，Word暂停时保留草稿状态，不为补截图重复发包。
